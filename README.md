# Smart Library Management System

An award-winning IoT application engineered to automate book cataloging and real-time asset tracking workflows for campus libraries. This project was awarded a **Merit Rank** at the institutional technical project showcase during my 2nd semester.

## Core Features
* **Real-Time Data Capture:** Integrated a mobile scanner interface with an ESP32 microcontroller for instantaneous barcode parsing.
* **Automated Asset Tracking:** Programmed core validation logic to update book availability states dynamically.
* **Efficient Transactions:** Reduced manual logging delays and streamlined book issue/return verification cycles.

## Tech Stack
* **Microcontroller:** ESP32
* **Firmware Framework:** Arduino IDE Architecture
* **Core Language:** C++
* **Hardware Interfacing:** Wireless Data Protocols & Scanner Modules
